# 川-Coder 个人博客

一个基于原生 HTML + CSS 的静态个人主页,采用「A4 纸张」风格的版面,用来展示个人介绍、比赛经历、编程作品与日常课程表。

## 预览

| 首页 | 作品页 |
| --- | --- |
| `index.html` | `works.html` |

- **首页** `index.html`:个人介绍、比赛经历(国/省/校三级奖牌)、编程作品入口、课程表、联系页脚。
- **作品页** `works.html`:编程作品的图文展示(3D 大屏、学生管理系统、Python 词云图)。

## 技术栈

- 纯静态前端:**HTML5** + **CSS3**,无任何框架与构建工具
- 无需安装依赖,浏览器直接打开即可浏览

## 页面导航

| 锚点 | 内容 |
| --- | --- |
| `#introduce` | 个人介绍 |
| `#competition` | 比赛经历 |
| `#work` | 编程作品 |
| `#course` | 课程表 |
| `#link` | 联系我 |

## 运行方式

方式一:直接双击 `index.html` 在浏览器中打开。

方式二:本地起一个静态服务器(推荐,资源加载更稳定):

```bash
python -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`。

## 项目结构

- 页面为静态单页,内容(个人简介、课程表、联系方式等)直接在 HTML 中维护;如需更新,直接编辑对应文件即可。
